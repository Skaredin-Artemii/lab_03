# Каталог учебных аудиторий (catalog)

Пакет для хранения и управления каталогом учебных аудиторий. 
Позволяет добавлять, удалять, искать аудитории, а также сохранять и загружать их из JSON.

## Установка

Требуется Python 3.10 или выше.

```bash
pip install -e ".[dev]"
```
Установка в режиме разработки (editable) вместе с инструментами для тестирования (`pytest`, `ruff`).

## Сущность (Classroom)

Сущность реализована через `@dataclass(frozen=True)`. Все поля обязательны.
Инварианты проверяются при создании в `__post_init__`. Невалидный объект не может быть создан.

- `item_id` — уникальный строковый ID (нормализуется: обрезаются пробелы по краям).
- `name` — название аудитории (нормализуется).
- `category` — строго одно из: `lecture`, `lab`, `seminar`, `computer`, `sport`.
- `year` — год последнего капитального ремонта (целое число от 1950 до 2026).
- `capacity` — вместимость (целое число > 0).
- `building` — корпус (нормализуется).

## Каталог (Catalog)

Хранит объекты в памяти. Внутреннее хранилище — словарь `dict[str, Classroom]`.

- `add(item)` — добавить аудиторию. Вызывает `DuplicateIdError` при дубликате ID.
- `get(item_id)` — получить по ID. Вызывает `ItemNotFoundError`, если нет.
- `remove(item_id)` — удалить. Вызывает `ItemNotFoundError`, если нет.
- `find_by_category(category)` — поиск по точному совпадению категории. Возвращает новый список.
- `find_by_name(stroka)` — поиск по подстроке в названии (нечувствителен к регистру). Возвращает новый список.
- `__len__()` — количество аудиторий в каталоге.
- `__iter__()` — итерация по аудиториям. 
**Порядок детерминирован и совпадает с порядком добавления.** 
При удалении и повторном добавлении элемент уходит в конец.
- `__contains__(item_id)` — проверка наличия ID в каталоге.

## Хранение (JSON)

Сохранение и загрузка в формате JSON.
В корне документа обязательно есть поле `format_version` (текущая версия: 1).

Пример файла `catalog.json`:
```json
{
  "format_version": 1,
  "items": [
    {
      "item_id": "A-101",
      "name": "Аудитория информатики",
      "category": "computer",
      "year": 2015,
      "capacity": 30,
      "building": "А"
    }
  ]
}
```

- `save_catalog(catalog, path)` — сохраняет каталог.
- `load_catalog(path)` — загружает каталог. Возвращает **новый** объект `Catalog`. При поврежденном файле старый каталог не изменяется (транзакционность).
- `load_into(catalog, path)` — транзакционно добавляет данные из файла в существующий каталог. Если в файле есть ID, который уже есть в каталоге, вызывает ошибку и ничего не добавляет.

## Исключения

Все исключения наследуются от базового `CatalogError`:
- `InvalidItemError` — нарушены инварианты сущности.
- `DuplicateIdError` — ID уже существует в каталоге.
- `ItemNotFoundError` — ID не найден.
- `UnsupportedFormatVersionError` — неподдерживаемая версия JSON.
- `CorruptedFileError` — поврежденный JSON или неверная структура файла.

## Запуск

Чтобы убедиться, что пакет работает, запустите демонстрацию:
```bash
python -m catalog
```
(Выведет пример создания, сохранения, загрузки и поиска аудиторий).
