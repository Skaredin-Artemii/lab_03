Каталог учебных аудиторий (catalog)

Пакет для работы с каталогом учебных аудиторий: можно добавлять, удалять
и искать аудитории, а также сохранять всё в JSON и загружать обратно.


Установка

Нужен Python 3.10 или выше.

    pip install -e ".[dev]"

Ставит пакет в режиме разработки (editable) вместе с pytest и ruff.


Сущность Classroom

Сделана через dataclass(frozen=True), все поля обязательные.
Вся проверка в __post_init__, поэтому невалидный объект просто
не получится создать.

    item_id   - уникальный ID (пробелы по краям обрезаются)
    name      - название аудитории (тоже обрезается)
    category  - строго одно из: lecture, lab, seminar, computer, sport
    year      - год последнего ремонта, целое от 1950 до 2026
    capacity  - вместимость, целое больше нуля
    building  - корпус (обрезается)


Каталог Catalog

Внутри обычный словарь dict[str, Classroom].

    add(item)                - добавить. Если id уже есть - DuplicateIdError
    get(item_id)             - достать по id. Если нет - ItemNotFoundError
    remove(item_id)          - удалить. Если нет - ItemNotFoundError
    find_by_category(cat)    - список всех аудиторий этой категории (новый список)
    find_by_name(stroka)     - все, где в названии есть эта подстрока,
                               без учёта регистра. Тоже новый список
    len(cat)                 - сколько аудиторий в каталоге
    iter(cat)                - идёт в том же порядке, в каком добавляли.
                               Если удалить и добавить заново - уйдёт в конец
    "A-101" in cat           - проверка, есть ли такой id


Сохранение в JSON

Файл выглядит примерно так:

    {
      "format_version": 1,
      "items": [
        {
          "item_id": "A-101",
          "name": "Аудитория информатики",
          "category": "computer",
          "year": 2015,
          "capacity": 30,
          "building": "А"
        }
      ]
    }

    save_catalog(catalog, path)  - записать каталог в файл
    load_catalog(path)           - прочитать и вернуть новый каталог.
                                   Если файл битый - упадёт с ошибкой,
                                   существующий каталог не тронется
    load_into(catalog, path)     - добавить всё из файла в существующий каталог.
                                   Сначала проверяет, что ничей id не пересекается,
                                   и только потом добавляет. Если хоть один id
                                   уже есть - падает и ничего не добавляет


Ошибки

Все наследуются от базового CatalogError:

    InvalidItemError              - не прошло проверку модели
                                    (или неверные поля в файле)
    DuplicateIdError              - такой id уже есть в каталоге
    ItemNotFoundError             - id не найден
    UnsupportedFormatVersionError - в файле другая версия формата
    CorruptedFileError            - файл битый или не того формата


Как посмотреть, что работает

    python -m catalog

Покажет создание, поиск, сохранение/загрузку и удаление.


Проверка

    python -m pytest
    python -m ruff check .
